# Changelog

All notable changes to MacSwitch are listed here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Versions follow [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-21

### Added

- Press `fn + 1` to `fn + 9` to select a keyboard layout.
- Menu bar icon with the key map and a **Launch at login** switch.
- Assign any layout to any key from the menu. The choice is saved.
- **Reset to system order** in the menu.
- App icon.
- Universal build for Apple Silicon and Intel, macOS 13 or later.
